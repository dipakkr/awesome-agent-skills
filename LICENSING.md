# Licensing

The root MIT licence covers original repository tooling and documentation.
Each original skill has a root `LICENSE.txt` applying MIT to Claude Directory's
original instructions and code in this repository edition. Earlier private ZIP
releases and website delivery are unchanged.

Embedded third-party libraries, fonts and other materials retain their own
notices and terms. MIT does not replace those licences or grant rights in
third-party brands, user-supplied assets or external provider services.

The website also includes adapted packages whose redistribution rights remain
unresolved. Those packages are excluded from this public repository and its
source catalogue. Inclusion on the website alone does not authorize a public
source import. The sync tool imports only packages marked original; validation
also requires the original-source publication status. Source changes still need
review for any newly introduced third-party material.

Rendered recordings and presentation exports under example folders are omitted.
Reusable source assets retain their existing notices. Website pages provide the
available previews; `catalog.json` records omissions for included skills.
