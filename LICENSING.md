# Source licensing and publication status

The root MIT licence covers the repository's original tooling and documentation.
Each of the 106 original skill packages has a root `LICENSE.txt` applying MIT to
Claude Directory's original instructions and code in this repository edition.
This follows the owner's direction to prepare an open-source skills collection.
It does not modify earlier private ZIP releases or the website's paid delivery.

Embedded third-party libraries, fonts and other materials retain their own
notices and terms. MIT is not a replacement licence for those materials or a
grant of rights in third-party brands, supplied assets or provider services.

## Adapted packages

Twenty catalogue packages carry provenance identifying a privately adapted
Skillry archive with redistribution/resale permission unconfirmed. Launch Video
also contains an adapted third-party film engine with unresolved distribution
rights. Their original notices and source files are preserved here; this
repository does not relicense them as MIT.

All 21 are marked `third-party-review-required` in `catalog.json` and the
[source index](CATALOG.md). Inclusion here is local preparation, not a claim
that these packages are open source or approved for public redistribution.

Before a complete public release, establish permission for those packages or
replace the affected material with independently authored implementations.
Alternatively, publish a separate export of cleared packages, keeping all
packages in this local collection. Do not publish this repository's full Git
history if it contains uncleared material. No public remote has been configured.

## Preview outputs

Generated recordings and presentation exports under example folders are omitted
from this source collection. `catalog.json` lists every omitted file and reason.
Use each skill's website link to inspect available previews. Reusable source
assets are retained, along with their existing notices.
