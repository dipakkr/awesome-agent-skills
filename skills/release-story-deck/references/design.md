# Visual directions for Release Story Deck

Choose a direction that fits the audience, or develop another coherent one. These are reusable visual grammars, not mandatory demo brands. Each example has a distinct composition, type system and visual motif. A color swap alone is not a new design.

## Prism Relay
Sculptural acrylic photography, oversized product type, technical annotations and interface specimens.

- Example: `relay`. Display type: Arial; supporting type: Arial. Palette: #E7F1F5, #14363F, #D4512B.
- Audience: Product teams. Runtime topic: A concept workspace for small product teams.
- Inspect the full example deck, including its evidence and closing pages. Adapt the visual idea to new content, not just the example headline.

## Library Pop
Oversized serif mastheads, a colorful book-spine motif and modular library compositions.

- Example: `shelf`. Display type: Georgia; supporting type: Arial. Palette: #302485, #FFF5CE, #F5ACCB.
- Audience: Product teams. Runtime topic: A concept reference library for creative studios.
- Inspect the full example deck, including its evidence and closing pages. Adapt the visual idea to new content, not just the example headline.

## Coastal Rhythm
Full-frame coastal photography, quiet serif titles, horizon rules and spacious editorial pacing.

## Art direction before layout
Decide the audience, visual metaphor, typography, image treatment and page rhythm before drawing. Present a consistent world across cover, explanation, evidence and closing. Alternate scene-led pages, type-led pages and genuinely useful diagrams. A new example should change at least composition, typography and image/diagram treatment; changing only color or copy is insufficient.

## Content and artwork
Use a real, relevant visual subject rather than empty decoration. Keep live copy editable. Use supplied licensed imagery or generate original art; do not copy a reference site’s assets. Use an available installed font or package a licensed font. The examples use common system fonts, which can substitute on another computer.

## Review as a collection
Render all covers as one contact sheet. If adjacent designs have the same silhouette or hierarchy, revise them. Then inspect every interior slide: no clipped type, unreadable photo overlays, repeated filler panels or unlabelled invented statistics. Keep source qualifications near claims. The contact sheet is a diversity check, not a substitute for full-deck review.
