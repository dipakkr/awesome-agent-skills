## Tool setup

An agent with an image-generation tool. Product photos and a logo are optional runtime inputs; actual-product work needs your product reference.

Uses your own agent and image-generation allowance. No separate paid API was called for these examples.

## A new request

```text
Use $texture-and-detail to create a citrus mist image from my brief. Use my attached product image and logo if provided; otherwise omit the logo. Keep the result ready to use.
```

Ask for the output files, inputs, prompt or build command, and a review of each result. Four requested outputs are not proof that all four have been generated successfully.
