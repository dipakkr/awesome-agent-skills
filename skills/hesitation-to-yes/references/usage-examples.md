# Four worked examples

Authored concept films. Each changes the subject, objection, fixture data, command and background. Not independent customer/agent reuse.

## 01. Stocknote: product notes

Use $hesitation-to-yes to make a 32-second concept film for Stocknote. Follow examples/01/brief.json and its data.json. Use the blueprint background, the repeated objection "our product facts", the turn "Now grounded" and the command "/catalog". Keep the posts explicitly fictional. Derive the findings from the supplied fixture and show those records as the output. Deliver a silent 1920x1080 MP4, editable inputs, preview and proof HTML locally.

```sh
python3 <installed-skill>/scripts/render.py <installed-skill>/examples/01/brief.json --out output/example-01
```
