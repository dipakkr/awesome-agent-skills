# Input contract

Use `examples/caching/brief.json` as a structural example. The same source renders every example; changing a topic does not require editing JavaScript when the diagram fits the supported grammar.

| Field | Requirement |
| --- | --- |
| id | Lowercase hyphenated slug; identifies the lesson. |
| title | 1–34 characters. Main video title. |
| subtitle | 1–48 characters. Editorial brief metadata; not drawn as an extra headline. |
| takeaway | 1–76 characters. Final summary card. |
| theme | `mint`, `peach`, `violet` or `night`. Changes room, trim, clothing and tutor palette. |
| boards | 1–8 states. Each has heading (1–30 characters), note (up to 56), nodes (1–3) and kind. |
| nodes | Each has `label` (1–16 characters) and `icon`. |
| icon | `book`, `shelf`, `bell`, `shop`, `phone`, `gate`, `ticket`, `worker`, `tray`, `clock`, `database`, `lightning`. |
| kind | `flow`, `cycle` or `queue`. |
| turns | 8–20 turns, maximum 180 words overall. |
| turn.speaker | `student` or `tutor`. |
| turn.text | 1–108 characters. Exact spoken text and caption. Split long ideas into separate turns. |
| turn.board | Zero-based board state index. |
| turn.shot | `wide`, `student`, `tutor`, `board`. Reaction shots may show the listener. |

Voice durations, pauses and mouth-energy curves are generated by `prepare.py`; do not invent those values for a final film. English examples have been tested. Other languages, right-to-left scripts and longer words require text/layout and pronunciation review.

Example validation:

```sh
python3 <skill>/scripts/prepare.py my-brief.json --out output/check --validate-only
```

Use fresh output directories for changed inputs, voices or models. Do not point an output folder at the skill's source directory.
