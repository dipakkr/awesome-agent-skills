# Team Values Card

## Runtime input contract
Run with a brief, never by editing skill files. Accept `text`, `brand` (name, palette, typography), `logo`, `image`, `product`, `audience` and `placement` as optional inputs. Ask for the approved value, working habit or real team story when absent. Example briefs are fictional demonstrations, never defaults. Omit a missing logo cleanly; never render a placeholder. Preserve supplied logos and authorized photos through image editing. Do not add Claude Directory branding.

## Workflow
1. Identify the employer-brand message and whether it is an aspiration, approved company value or documented team story. Do not turn an aspiration into a proven claim. Include hiring roles, benefits, locations or dates only when supplied and verified by the user.
2. Choose a square feed composition. For a real team story, use authorized supplied photographs with identity preserved. Without employee photos, use clearly illustrative people or objects; never fabricate documentary photographs of an actual team.
3. Reduce the message to one short headline. Choose a culture-specific scene such as shared discussion, careful making or a welcoming workspace. Do not use generic praise, fake quotations or testimonial badges. Explain the working value through the illustration.
4. Write an editable brief and a full generation prompt quoting approved words exactly. Generate a finished raster image with the built-in image tool. Inspect supplied references first and state their roles when editing.
5. Visually inspect the returned image for text accuracy, representation, legibility, margins and any invented claims. Measure the native dimensions and file size. Regenerate or edit errors using the image tool; keep every version with its full prompt.
6. Deliver the accepted image, editable brief/prompt, actual dimensions and alt text. Provide a plain caption suggestion distinguishing an aspiration from a documented fact. Do not promise engagement, employment outcomes or layered PSD/SVG files.

## Placement guidance
A square 1:1 canvas is supported by LinkedIn single-image ad guidance, which recommends 1200×1200 pixels. That recommendation is not proof of organic post reach. Measure the actual generated image, preserve the square aspect, and check the upload preview before posting.
