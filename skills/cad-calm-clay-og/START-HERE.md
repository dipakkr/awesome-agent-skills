# Make your own Calm Clay OG image

Unzip this folder and open its parent workspace in your coding agent. Say: “Read cad-calm-clay-og/SKILL.md and tell me which connected image tool is available.” Installing the skill itself does not install an image model.

Then paste:

```text
Read cad-calm-clay-og/SKILL.md. Create a new image for [my topic/product].
Audience: [who should care]. Placement and dimensions: [where it will appear].
Exact headline: [my short headline]. Supporting copy: [optional].
Brand palette and reference assets: [optional; omit branding if absent].
Use a fresh composition, preserve my wording and generate the actual image
with my connected image tool. Review it at full size and thumbnail size.
Deliver the final image, editable brief and exact prompt.
```

Open examples/ for four finished images and their inputs. Change the subject and copy in your request; you do not need to edit SKILL.md. For another provider/model, follow references/image-tools.md. Each actual output needs review; no provider comparison is bundled.
