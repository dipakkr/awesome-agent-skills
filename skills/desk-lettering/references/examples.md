# Desk Lettering: worked examples

Two distinct inputs use the same packaged generator. These are author-executed geometry examples, not physical prints.

## 1. ORBIT studio nameplate

Use `$desk-lettering` with [this editable input](../examples/01.json). Generate STL, 3MF, an exact-mesh poster, an interactive preview and a six-second turntable using `--video`.
