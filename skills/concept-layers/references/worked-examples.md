# Concept Layers: four worked examples

These instructions and content briefs were authored before the native image-generation calls. The same agent constructed the generation prompts from the skill and reviewed the results. This is not an independent agent or fresh Claude installation test.

Use an agent with a real image-generation tool. Extract this skill folder into your agent’s supported skills location, open SKILL.md, and paste a request below. The skill does not bundle an image model or API entitlement.

The PNGs are completed raster examples. JSON briefs and prompt files are editable inputs; they are not layered artwork. Different models or reruns may vary. Use the examples to learn the layout, then change the subject and exact copy in your request.

## Adapt the pattern

Replace the topic, audience, title, grouped copy and palette. Keep this skill’s layout rules. For a four-output set, give four distinct subjects, not four colour variants. Supply optional logo/CTA explicitly; none is inserted by default.

Inspect every label, count and connector before publishing. Record errors, preserve the failed attempt, and request a focused correction. Full generation prompts are in references/prompts and all content maps are in references/examples.json.

Folder-tree examples describe illustrative workspaces. They do not include the software or twelve working Markdown systems depicted in the artwork. No LinkedIn engagement or virality test was performed.
