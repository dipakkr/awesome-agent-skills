# Tall Product Story: worked examples

Read SKILL.md first, then choose the closest example below. Keep its visual rules and change the subject, audience, content and optional brand inputs in your request. You do not need to edit the skill file.

This package documents **4 distinct output example(s)**. Extra gallery views are not counted as separate examples.

## Tool setup

An agent with an image-generation tool. Product photos and a logo are optional runtime inputs; actual-product work needs your product reference.

Uses your own agent and image-generation allowance. No separate paid API was called for these examples.

## A new request

```text
Use $tall-product-story to create a reading corner image from my brief. Use my attached product image and logo if provided; otherwise omit the logo. Keep the result ready to use.
```

For four variations, explicitly request four different subjects and provide a separate brief for each. Keep the skill style consistent. Ask for the output files, inputs, prompt or build command, and a review of each result. Four requested outputs are not proof that all four have been generated successfully.

## Review and limitations

The generated examples are concepts. No sales-lift or platform-approval test was run. Optional supplied-logo compositing was not exercised in these examples. All four files are exactly 2:3 at 1024 × 1536.

Check actual output dimensions, wording, item counts, media playback or file validity as appropriate. Never count a recolour, crop, screenshot or proposed prompt as a new completed deliverable. Keep failed attempts and describe missing evidence honestly.
