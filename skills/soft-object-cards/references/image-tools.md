# Image tools and model choice

The style instructions and editable prompts are independent of a particular image provider. Use the image-generation or editing tool connected to the user's agent, and follow that tool's current instructions and capabilities. Installing this SKILL.md does not give a text-only agent an image generator or API access.

Before generating, identify the available tool and whether it supports reference images, exact requested dimensions and image editing. For new concept artwork use generation. For a supplied real portrait, logo, product or screenshot, use an editing/compositing path that preserves the reference. If that tool cannot preserve the required identity, explain the limitation and offer a suitable connected tool or a prompt handoff. Never claim an image was generated when only a prompt was written.

If the user names a model, use it when available. Do not silently substitute another provider, incur a new account charge or describe a different model's output as theirs. Keep provider-specific flags separate from the semantic prompt: subject, exact copy, composition, palette, material, references and exclusions.

For a requested model comparison, run the same brief through each authorized connected model, retain outputs, record actual tool/model/version when exposed, and compare copy accuracy, reference fidelity, anatomy/geometry, hierarchy and thumbnail readability. Do not label an untested provider as better or supported by a tested integration.

These four bundled images were generated with the built-in image_gen tool. The interface did not expose its underlying model/version. No cross-model benchmark or external provider adapter is included. The same prompts can be adapted to another connected tool, but its results require a new review. Provider access, costs and usage terms belong to the user's own account.
