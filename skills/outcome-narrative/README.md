# Outcome Narrative

Copy this folder into your agent’s skills folder. Invoke `$outcome-narrative` with a new brief. No source edits required. See SKILL.md for inputs and export steps.

Three example decks include JSON, original assets, HTML and native-object PowerPoint. All examples are fictional. Open an example HTML directly in your browser. Text edits save into a new HTML file.

Original workflow and runtime by Claude Directory. Research references inform presentation structure; no Skillry code or artwork is bundled.
