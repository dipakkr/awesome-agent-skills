# Ad Motion Export: worked examples

Read SKILL.md first, then choose the closest example below. Keep its visual rules and change the subject, audience, content and optional brand inputs in your request. You do not need to edit the skill file.

This package documents **1 distinct output example(s)**. Extra gallery views are not counted as separate examples.

## Tool setup

Python 3.10+, FFmpeg and FFprobe with libx264. Supply your own local artwork or video clips; soundtrack is optional.

Local rendering. No generation API or subscription is required by the exporter.

## A new request

```text
Use $cad-ad-motion-export to assemble two approved creatives into an eight-second silent review sequence, four seconds per creative, at 1080 × 1350. Also export a preview GIF.
```

For four variations, explicitly request four different subjects and provide a separate brief for each. Keep the skill style consistent. Ask for the output files, inputs, prompt or build command, and a review of each result. Four requested outputs are not proof that all four have been generated successfully.
