# Sound direction

Version2 uses an original harmonic arrangement, restrained rhythm, stereo ambience and effects timed to scene actions. Brush films use electric keys and warm pads; pixel films use softer chip melody, rounded bass, drums and a four-note ending. The brand argument deterministically selects variation; COMMON and PATCH use transposed arrangements.

Run `node compose-score.mjs /new/score.wav brush|pixel seconds BRAND`. Requires FFmpeg. The composer performs measured two-pass mastering toward-16LUFS and-1.5dBTP. Check the encoded AAC output too. Never replace an accepted score in place. For different timelines, revise cue times and score structure to match the picture. A final fade protects the ending. No external music samples or voiceover.
