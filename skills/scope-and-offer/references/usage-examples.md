# Scope And Offer: worked examples

Read SKILL.md first, then choose the closest example below. Keep its visual rules and change the subject, audience, content and optional brand inputs in your request. You do not need to edit the skill file.

This package documents **3 distinct output example(s)**. Extra gallery views are not counted as separate examples.

## Tool setup

An agent and Python 3 for generation. A browser opens the offline HTML. PowerPoint export needs python-pptx and Pillow; illustrative work also needs an image tool or supplied artwork.

Use your own agent and optional image-generation allowance. No paid API is required to render or view the HTML decks.

## A new request

```text
Use $scope-and-offer to create a fresh presentation from my brief and audience. Use my supplied evidence and optional branding; omit a logo if none is supplied. Deliver editable HTML, source JSON and PowerPoint.
```

For four variations, explicitly request four different subjects and provide a separate brief for each. Keep the skill style consistent. Ask for the output files, inputs, prompt or build command, and a review of each result. Four requested outputs are not proof that all four have been generated successfully.
