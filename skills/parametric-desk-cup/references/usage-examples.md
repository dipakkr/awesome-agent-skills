## Tool setup

An agent that can run Python 3. The generator uses only the standard library. A browser opens the preview; a slicer is needed for print preparation.

No paid generation API or CAD subscription is required. Printing materials and hardware are separate.

## A new request

```text
Use $parametric-desk-cup to make a 90 mm tall twisted pen cup. Give me editable parameters, STL, 3MF and a rotatable preview.
```
