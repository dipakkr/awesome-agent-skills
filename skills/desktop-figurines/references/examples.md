# Desktop Figurines: worked examples

Two distinct inputs use the same packaged generator. These are author-executed geometry examples, not physical prints.

## 1. Pip desk robot

Use `$desktop-figurines` with [this editable input](../examples/01.json). Generate STL, 3MF, an exact-mesh poster, an interactive preview and a six-second turntable using `--video`.

[Recorded preview](../examples/recorded/01/poster.png) · [STL](../examples/recorded/01/model.stl) · [3MF](../examples/recorded/01/model.3mf) · [Turntable](../examples/recorded/01/turntable.mp4)
