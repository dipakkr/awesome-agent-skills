Read SKILL.md first, then choose the closest example below. Keep its visual rules and change the subject, audience, content and optional brand inputs in your request. You do not need to edit the skill file.

## Tool setup

An agent with an image-generation tool. Supply a topic or exact grouped copy. A logo is optional. Installing these instructions does not provide an image model.

Uses your connected image tool allowance; provider pricing varies.

